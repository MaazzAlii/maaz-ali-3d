# Assets to add

This folder is intentionally missing a few binary files that only you can provide:

1. **resume.pdf** — your actual resume, referenced by the "Download Resume" button in `lib/data.ts` (`profile.resumeUrl`). Drop it in at `public/resume.pdf`.
2. **og-image.png** (1200×630) — the image shown when your site is shared on social media (referenced in `app/layout.tsx`). A clean screenshot of your hero section works well.
3. **favicon.ico** — your site icon, referenced in `app/layout.tsx`. You can generate one at https://realfavicongenerator.net using your initials ("MA") on the electric-blue (#2F6FFF) accent color.

Delete this file once you've added them.
